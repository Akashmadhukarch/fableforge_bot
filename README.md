# fableforge_bot
📚 What Is FableForge?

FableForge is an AI Picture Book Generator.

You give:

“A shy dragon who learns to fly”

And the system automatically:

✍️ Writes a full children’s story

🎨 Creates images for each page

📄 Combines them into a PDF book

(Optional) Stores data for future use

So it turns one sentence → complete picture book.
